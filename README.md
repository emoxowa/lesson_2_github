# course

## Что это

Небольшой учебный репозиторий для курса по вайбкодингу на Python и базовой работе с Git. Сейчас в проекте одна точка входа — скрипт `main.py`, который выводит приветствие в консоль. 

## Как запустить / проверить

Требования: Python 3 (проверка версии — `python3 --version`).

Из корня проекта:

```bash
python3 main.py
```

Ожидаемый вывод:

```text
Hello, World!
```

Опционально — виртуальное окружение (рекомендуется для дальнейших заданий):

```bash
python3 -m venv .venv
source .venv/bin/activate   # macOS / Linux
python main.py
```

Проверка, что Git видит только нужные файлы: `git status` (каталоги вроде `.venv` и `__pycache__` не должны попадать в коммиты благодаря `.gitignore`).

## Что было сложным / что понял(а)

**Сложным:** разобраться, какие файлы не нужно коммитить (venv, секреты в `.env`, `__pycache__`), и как это зафиксировать один раз в `.gitignore`, а не удалять вручную перед каждым коммитом.

**Понял(а):**

- Git хранит историю изменений; `.gitignore` задаёт правила «не отслеживать» для локального мусора и секретов.
- Запуск скрипта — из терминала командой `python3 main.py` (или `python` внутри активированного venv).
- Минимальный рабочий цикл: правка кода → проверка запуском → `git add` / `git commit` → при необходимости push на remote.
